WANDERLUX TRAVEL AGENCY - ICT502 ASSESSMENT 2 PROJECT

PROJECT CONTENTS
- index.html             Home page
- destinations.html      Destinations and services page
- calculator.html        JavaScript trip cost calculator
- appointment.html      Appointment request form
- about.html             About us page
- contact.html           Contact page and embedded map
- assets/style.css       Shared responsive stylesheet
- assets/main.js         Navigation, slider, scroll reveals, calculator and forms

HOW TO RUN
1. Extract the ZIP folder.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Navigate between all six pages using the navigation menu.

FUNCTIONALITY
- Homepage rotating hero slider (automatic and arrow controls).
- Responsive navigation menu for mobile screens.
- Scroll-triggered reveal animations using IntersectionObserver.
- Trip cost calculator using preset sample rates and travel-style multipliers.
- Appointment form with browser validation and a confirmation message.
- Contact form validation and mailto email preparation.
- Google Maps embed on the contact page.
- Semantic page structure, meta descriptions, descriptive titles, labels and image alt text.

IMPORTANT BEFORE SUBMISSION / LIVE DEPLOYMENT
1. Replace hello@wanderlux.example and the sample telephone/address details with approved project details.
2. The appointment form is currently a front-end demonstration only; it does not store or transmit submissions. Connect a form backend/service (for example, FormSubmit or Netlify Forms) if real online submissions are required.
3. The contact form uses mailto and opens the visitor's configured email application. For direct server-side email delivery, connect a form service or backend.
4. Destination photos and Google Fonts load from external services, so internet access is needed for those assets.
5. Package prices and calculator rates are illustrative sample figures in USD, not live travel quotations.
6. Test all pages, form validation, calculator values, responsive layouts and image loading before submission.

DEPLOYMENT
GitHub Pages:
- Create a GitHub repository and upload the extracted project files.
- Ensure index.html is in the repository root.
- In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then save.
- Wait for the published URL and add it to the assessment report.

Netlify:
- Sign in to Netlify and choose Add new site > Deploy manually.
- Drag the extracted project folder into the deployment area.
- Copy the generated public URL and include it in the report.

This project is a front-end website prototype for the ICT502 scenario. Verify and customise all content before final assessment submission.
